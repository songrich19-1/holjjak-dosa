# 홀짝 도사 🎲

술자리·밥값 내기에서 **누가 쏠지** 정해 주는 폰 게임. 설치 없이 `index.html` 하나로 돌아갑니다.

## 게임
- **홀짝 주사위** — 인원수를 정하고 1번부터 순서대로 홀/짝을 고른 뒤 주사위 2개를 던진다. 틀린 사람이 쏜다.
- **화살표 술겜** — 폰을 가운데 놓고 화살표 한가운데를 누르면 룰렛처럼 돌다가 멈춘다. 가리키는 사람이 쏜다.
- **시간 초 맞추기** — 판마다 3~8초 중 랜덤 목표가 정해진다. 시작을 누르고 감으로 멈춰 목표에 가장 가까운 사람이 이긴다.
- **젓가락 뽑기** — 대나무 통에서 젓가락을 뽑는다. "주인공은 너야 너"를 뽑으면 쏘고 그 자리에서 끝.

## 실행
`index.html`을 브라우저에서 열면 됩니다. 이미지와 주사위(WebGL)까지 전부 한 파일에 들어 있어 오프라인에서도 동작합니다.

## 만든 방법
Claude Code와 함께 만들었습니다. 주사위는 WebGL 레이마칭으로 그리고, 던지기는 간단한 물리 시뮬레이션입니다.
